# LUMEN - prototype v0.5

2D Christian platformer prototype built with Godot 4.
Carry the flame through the darkness (John 8:12).

Play: https://xatusbetazx17.github.io/lumen-prototype/

## v0.5 — random worlds, bosses, save, pause, any controller
- **Random worlds**: World 1 is the handcrafted tutorial; every world after is
  procedurally generated with a fresh seed — 3 rotating themes
  (Crystal Caverns, Dawn Peak, Shadow Valley), seeded chunk templates,
  difficulty that scales with each world
- **Two bosses**: El Devorador de Luz (lunges) and La Tejedora de Sombras
  (spits shadow orbs, weaves wisps) alternate at the end of each world
- **Progress saves**: title screen continues at your furthest world, best score kept
- **Pause menu**: Esc / P / Start — resume, restart the world, back to title
- **Any controller**: keyboard, any standard gamepad
  (stick/D-pad move, A jump, X/RB dash, Start pause), touch buttons

## v0.2 — the world is alive
- Parallax, dust, embers, squash & stretch, screen shake, procedural SFX,
  light bridges, wisps, 5 verses (Reina-Valera 1909)

Controls: A/D or arrows to move, Space to jump, Shift to dash, R to restart,
Esc to pause. Touch buttons appear automatically on phones/tablets.
